
## Installing

- **Homebrew:** `brew install --cask ramanan-bala/unlatch/unlatch` (installs macFUSE too). Command-line tools only, built from source: `brew install ramanan-bala/unlatch/unlatch`.
- **DMG:** install [macFUSE](https://macfuse.github.io) first, then drag Unlatch to Applications.
- This build is **not signed with an Apple Developer ID**. The first time, right-click Unlatch in Applications and choose Open, or allow it in System Settings > Privacy & Security > Open Anyway. `SHA256SUMS` lists the checksums.
- Source: `unlatch-<version>.tar.gz`, or the tag. Licenses and the written source offer are in the app (Settings > About > Licenses and source) and in the DMG's Notices folder.

See [docs/install.md](https://github.com/Ramanan-Bala/unlatch/blob/main/docs/install.md) for details and [docs/troubleshooting.md](https://github.com/Ramanan-Bala/unlatch/blob/main/docs/troubleshooting.md) if something goes wrong.


## Installing

- **Homebrew:** `brew tap ramanan-bala/unlatch`, `brew trust --tap ramanan-bala/unlatch`, then `brew install --cask ramanan-bala/unlatch/unlatch` (installs macFUSE too). Command-line tools only, built from source: `brew install ramanan-bala/unlatch/unlatch`.
- **DMG:** drag Unlatch to Applications; its setup window installs [macFUSE](https://macfuse.github.io) for you (or install macFUSE yourself first).
- This build is **not signed with an Apple Developer ID**. The first time, right-click Unlatch in Applications and choose Open, or allow it in System Settings > Privacy & Security > Open Anyway. `SHA256SUMS` lists the checksums.
- Source: `unlatch-<version>.tar.gz`, or the tag. Licenses and the written source offer are in the app (Settings > About > Licenses and source) and in the DMG's Notices folder.

Every one-time setup step: [README](https://github.com/Ramanan-Bala/unlatch#one-time-setup). See [docs/install.md](https://github.com/Ramanan-Bala/unlatch/blob/main/docs/install.md) for details and [docs/troubleshooting.md](https://github.com/Ramanan-Bala/unlatch/blob/main/docs/troubleshooting.md) if something goes wrong.
